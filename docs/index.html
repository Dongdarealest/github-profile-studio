GitHub Profile Studio

Type only your username. The Studio reads your real GitHub — your name, bio, languages and best repositories — fills everything in for you, then lets you mix beautiful blocks from different styles into a layout that is yours.

No sign-up, no token. Everything is read from the public GitHub API, in your browser.

or start from scratch, without fetching →

How do I put this on my GitHub? (30 seconds, by hand)
  1. On GitHub, create a new public repository named exactly your username (for example octocat/octocat). GitHub itself will tell you it is special.
  2. Open its README.md, delete the placeholder text, and paste what you copied here.
  3. Commit. Your profile updates immediately — every number on it then updates itself.
  4. No repository yet? The one-click Publish button in step 5 creates it for you.

5 · Publish straight to GitHub (optional)

One click: creates your profile repository if needed and commits this README — plus, if you tick them, the snake and Pac-Man workflows and the agent files. Uses a token you create, only in this tab, sent only to api.github.com, never stored.

Create one in 20 seconds: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Repository access: only your username repository → Permissions: Contents and Workflows, read and write.
